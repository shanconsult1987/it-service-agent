# Contoso IT Support Knowledge

## VPN Connection Problems

Symptoms:

- VPN cannot connect.
- VPN authentication fails.
- VPN connects and immediately disconnects.

Approved troubleshooting:

1. Confirm network connectivity.
2. Restart the VPN client.
3. Re-authenticate using corporate identity.
4. Confirm the VPN client is current.
5. Escalate to Network Operations if the problem persists.

Category: Network

Default priority: High

---

## Password Problems

Symptoms:

- User cannot sign in.
- Password has expired.
- Account is locked.

Approved troubleshooting:

1. Verify the user's identity.
2. Use the approved password reset process.
3. Check whether the account is locked.
4. Escalate to Identity Operations when required.

Category: Identity

Default priority: Medium

---

## Laptop Performance

Symptoms:

- Laptop is slow.
- Applications take a long time to start.
- CPU or memory usage is high.

Approved troubleshooting:

1. Restart the device.
2. Check available disk space.
3. Close unnecessary applications.
4. Install approved operating-system updates.
5. Escalate to Endpoint Operations if the problem persists.

Category: Endpoint

Default priority: Medium
